## 📋 Описание

**Tockler** — это бесплатное приложение для автоматического отслеживания использования компьютера и рабочего времени. Приложение предоставляет детальную аналитику о:

- 📱 Использовании приложений и заголовках окон
- 💻 Состоянии компьютера (бездействие, офлайн, онлайн)
- 📊 Интерактивной визуализации временной шкалы
- 📈 Ежедневной, еженедельной и месячной статистике использования
- 📅 Календарных представлениях и графиках

## ✨ Возможности

### 🎯 Основной функционал

- **⏱️ Отслеживание времени** — Вернитесь в прошлое и посмотрите, над чем вы работали
- **📱 Мониторинг приложений** — Отслеживайте, какие приложения использовались и их заголовки окон
- **📊 Аналитика использования** — Просматривайте общее время онлайн, паттерны использования приложений и тренды
- **📈 Интерактивная временная шкала** — Визуализируйте использование компьютера с помощью интерактивного графика
- **🌐 Кроссплатформенность** — Доступно для Windows, macOS и Linux

### 🎨 Интерфейс

- Поддержка светлой и тёмной темы
- Современный и интуитивный дизайн
- Адаптивная вёрстка

## 💻 Технологии

Tockler построен на современных веб-технологиях:

| Категория | Технологии |
|-----------|------------|
| **Фреймворк** | [Electron](https://electron.atom.io/) с [Vite](https://vitejs.dev/) и [TypeScript](https://www.typescriptlang.org/) |
| **Фронтенд** | [React](https://reactjs.org/) с [Chakra UI](https://chakra-ui.com/) |
| **Визуализация данных** | [D3.js](https://d3js.org/) и [Victory Chart](http://formidable.com/open-source/victory/docs/victory-chart/) |
| **Менеджер пакетов** | [pnpm](https://pnpm.io/) |
| **База данных** | SQLite с [Drizzle ORM](https://orm.drizzle.team/) |

## 🚀 Разработка

### 📋 Требования

- **Node.js** (рекомендуется последняя LTS версия)
- **Git**
- **pnpm** (включён в Node.js через corepack)

### ⚡ Быстрый старт

1. **Клонируйте репозиторий:**

```bash
git clone https://github.com/QuestGuideRF/tockler.git
cd tockler
```

2. **Включите pnpm:**

```bash
corepack enable pnpm
```

3. **Установите зависимости и запустите приложение:**

Для React клиента (рендерер):

```bash
cd client/
pnpm install
pnpm start
```

Для Electron главного процесса:

```bash
cd electron/
pnpm install
pnpm start
```

### 📁 Структура проекта

```
tockler/
├── client/          # React приложение (рендерер)
│   ├── src/         # Исходный код клиента
│   └── public/      # Публичные ресурсы
├── electron/        # Electron главный процесс
│   ├── src/         # Исходный код Electron
│   └── build/       # Ресурсы сборки
└── screenshots/     # Скриншоты для документации
```

### 📝 Логи

Логи хранятся в следующих местах:

- **Linux**: `~/.config/tockler/logs/main.log`
- **macOS**: `~/Library/Logs/tockler/main.log`
- **Windows**: `%USERPROFILE%\AppData\Roaming\tockler\logs\main.log`

## 🏗️ Архитектура

### Компоненты системы

Tockler построен на архитектуре Electron с разделением на главный процесс и процесс рендерера:

#### Главный процесс (`electron/`)
- Системные операции
- Фоновое отслеживание активности
- Операции с базой данных (SQLite)
- Обработчики IPC
- Управление жизненным циклом приложения
- Функциональность системного трея

#### Процесс рендерера (`client/`)
- React UI компоненты
- Управление состоянием (easy-peasy)
- Стилизация Chakra UI
- Компоненты визуализации данных
- Контроллеры представлений
- Взаимодействие с пользователем

### Типы отслеживания

Приложение отслеживает три основных типа данных:

1. **AppTrackItem** — Использование приложений (какие приложения были открыты и активны)
2. **StatusTrackItem** — Состояние системы (онлайн, бездействие, офлайн)
3. **LogTrackItem** — Ручные записи времени, созданные пользователем

### Состояния системы

Приложение отслеживает три основных состояния:

- **ONLINE** — Компьютер активен и используется
- **IDLE** — Компьютер включён, но не используется (таймаут бездействия)
- **OFFLINE** — Компьютер спит или выключен

Подпись относится к текущей версии проекта.
